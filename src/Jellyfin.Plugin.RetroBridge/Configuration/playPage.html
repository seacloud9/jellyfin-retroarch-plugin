RetroBridge

Play NES, Game Boy, and Game Boy Color games in RetroArch on a paired computer.

    In-browser play uses open-source emulators: RetroArch (GPL-3.0), FCEUmm (GPL-2.0-or-later), mGBA (MPL-2.0), and Nostalgist (MIT). Licenses and source code.
